# Catálogos verticales para celular

El diseño común de todos los PDF coloca dos productos por página, uno debajo del otro, sin tarjetas, bordes ni fondos añadidos. Cada imagen ocupa el ancho disponible y conserva su proporción completa. Los nombres y códigos se mantienen debajo de las imágenes. La última página puede contener un solo producto.

La página mide 595,28 × 1683,78 puntos: es un formato vertical alargado, elegido para lectura móvil al ancho de pantalla, no una hoja A4 convencional. El PDF tiene distribución fija; el visor debe permitir desplazamiento vertical y zoom. Los textos pequeños incluidos dentro de las fotos pueden seguir necesitando ampliación.

Se usa el mismo generador para catálogos filtrados, proyectores y la opción antigua de imágenes grandes. La versión de caché `all-catalogs-mobile-borderless-v8` crea enlaces nuevos; los documentos adjuntos a mensajes anteriores no cambian.

Validación: recuento de páginas, tamaño y número de imágenes para 1–5 productos en ambos generadores; comprobación visual con imágenes reales a 390 píxeles de ancho. Esto representa lectura al ancho de pantalla, no certifica el comportamiento de todos los visores móviles.
